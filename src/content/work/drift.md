## Overview

A Bayesian sequential testing framework that allows experimenters to make confident decisions earlier than traditional frequentist approaches. Implemented in R with a Shiny dashboard for real-time monitoring.

## Methodology

Uses beta-binomial conjugate priors with optional informative priors from historical data. Sequential analysis rules based on expected loss thresholds rather than arbitrary stopping rules.

## Impact

- 40% faster experiment resolution on average
- Maintains proper false positive control
- Interactive dashboard for stakeholder communication
