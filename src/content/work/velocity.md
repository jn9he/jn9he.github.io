## Overview

A comprehensive machine learning pipeline that predicts customer churn with 92% accuracy. Built using Python, scikit-learn, and XGBoost with careful feature engineering and model validation.

## Approach

The project leverages survival analysis techniques combined with gradient boosting to identify at-risk customers before they churn. Feature importance analysis revealed key behavioral indicators that precede customer departure.

## Results

- 92% prediction accuracy on holdout test set
- 15% improvement over baseline logistic regression
- Deployed as a real-time scoring API
