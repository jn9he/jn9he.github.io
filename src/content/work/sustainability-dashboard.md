## Overview

A cost-benefit and ROI analysis of university sustainability initiatives, paired with a dashboard for tracking green investment performance.

## Tech Stack

Python (Pandas, NumPy), Scikit-learn, Tableau.

## Approach

- Automated the data-ingestion pipeline to scrape, clean, and write utility and greenhouse gas metrics using Python (Pandas, NumPy).
- Applied Scikit-learn regression models to project energy cost trajectories and estimate carbon reduction curves over 5- and 10-year periods.
- Built an interactive Tableau dashboard surfacing green investment performance indicators for university administrators.

## Outcomes

- Quantified the financial and ecological footprint of several sustainability initiatives.
- Cut manual compilation work by automating the data pipeline behind the dashboard.
